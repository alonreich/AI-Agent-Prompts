## SYSTEM AUDIT DOMAINS & INVESTIGATION VECTORS
Systematically audit the repository against these architectural domains:

### 1. Concurrency, Race Conditions & State Tearing
- Insidious & High-Risk Race Conditions:
  - Detect Time-of-Check to Time-of-Use (TOCTOU) races where file existence, device readiness, or collection bounds are checked without continuous synchronization.
  - Detect out-of-order asynchronous completion: during rapid scrubbing, slider dragging, or search filtering, verify whether an earlier slow asynchronous task can resolve after a newer one and overwrite current state.
  - Audit multi-threaded collection access (e.g., standard List<T>, Dictionary<TKey, TValue> mutated across threads without locks or thread-safe primitives like ConcurrentDictionary or immutable snapshots).
- Lock Contention on the UI Thread: Audit every lock, Monitor.Enter, SemaphoreSlim, and ReaderWriterLockSlim acquisition on the UI thread. Flag locks shared between the UI thread and media/rendering/worker threads that can induce micro-stutters or deadlocks.
- Async Hygiene & Sync-over-Async: Flag all blocking invocations on asynchronous operations (.Result, .Wait(), .GetAwaiter().GetResult()) on the UI thread.
- Background Worker & Channel Pipelines: Ensure heavy workloads (file parsing, timeline slicing, waveform generation) run off the UI thread via decoupled background workers using lock-free message pipelines (System.Threading.Channels.Channel<T>).
- Timer Saturation: Replace uncoordinated polling timers driving UI state with push-based reactive streams or hardware-synced render loops.

### 2. Defensive Storage, Path Handling & Crash Persistence
- File System Fragility & Path Resolution:
  - Verify that file-saving routines never assume target paths exist. Audit for missing Directory.CreateDirectory checks before export or state writes.
  - Flag path sanitization flaws: verify handling of invalid filename characters, illegal symbols across file systems, path length limits, and relative directory escapes.
  - Audit error handling for external drive disconnections, read-only media, permission denials (UnauthorizedAccessException), and disk full (ERROR_DISK_FULL) conditions.
- Atomic File Persistence & Anti-Corruption:
  - Flag direct-to-destination file writes for critical user data or project recovery files. Enforce atomic write patterns (write to unique .tmp file -> flush to physical storage via FileStream.Flush(flushToDisk: true) -> atomic file replace via File.Move(..., overwrite: true)).
  - Ensure project state serialization (recovery.json, session state) never blocks user interaction. State must be snapshotted in memory and written to disk asynchronously via a background write-behind worker, diffing state deltas rather than writing full-tree documents on hot paths.
- In-Memory IPC vs. Disk Serialization: Flag sub-app transitions or IPC channels that serialize state to disk files (e.g., intermediate JSON files) to pass data between windows or processes. Migrate inter-process communications to high-throughput shared memory (MemoryMappedFile, anonymous/named pipes, or shared memory handles).

### 3. Video Pipeline, Zero-Copy GPU & Dynamic Balancing
- Zero-Copy & VRAM Invariants: Trace frames from hardware decoder output to viewport presentation. Flag any frame round-tripping across the PCIe bus to host CPU memory (CPU readbacks, desktop GDI/Skia rasterization, bitmap copies). Direct3D 11 / DXGI keyed mutexes, WGL, or Vulkan surfaces must retain textures strictly in VRAM.
- Dynamic GPU vs. CPU Workload Allocation: Match commercial NLE standards (e.g., DaVinci Resolve, Premiere Pro). The GPU must manage pixel manipulation, color space conversion, scaling, and shader passes; CPU threadpools must handle audio DSP, demuxing, timeline mapping, and filtergraph generation. Ensure the GPU is not starved or over-saturated by non-graphical tasks better handled by the CPU.
- Master Clock & A/V Timeline Drift: Ensure multi-track audio playback (gameplay audio, voiceover takes, background music) derives synchronization from a single master clock tied to the authoritative output timeline, preventing preview phase jitter and drift.

### 4. Color Science, Pixel Formats & Dynamic Range
- Color Space & Gamut Integrity: Audit color pipelines for accurate mapping between standard (BT.709) and wide-gamut (BT.2020) color spaces to prevent oversaturation or hue shifts during rendering.
- Dynamic Range & Transfer Functions: Verify handling of HDR10 and HLG metadata, peak luminance clamping, and tonemapping paths to avoid blown-out highlights or crushed shadows.
- Black Level & Range Compliance: Ensure correct handling of full-range (0-255) versus limited-range (16-235) YUV-to-RGB conversions to eliminate foggy blacks or clipped dark details.
- Memory Layout & Planar Formats: Audit decoder-to-renderer handoffs for modern 8-bit and 10/12-bit planar formats (such as NV12 and P010), ensuring stride, padding, and sub-sampled chrominance planes match target GPU texture resource views without corruption.

### 5. Audio Engine & Real-Time Constraints
- Low-Latency Audio Callback Safety: Audit audio output threads (WASAPI, CoreAudio, ALSA) for illegal operations. Flag any memory allocations, garbage collection triggers, lock acquisitions, or blocking system calls inside real-time audio callback loops that cause immediate audio dropouts or buffer underflows.
- Buffer Management & Synchronization: Ensure lock-free ring buffers or atomic transfer queues manage audio frames safely between decoder threads and real-time audio output drivers.

### 6. Seek Architecture, GOP Boundaries & Decoder Cache
- Frame Precision & Scrubbing: Audit seek logic for handling Closed GOPs, non-keyframe access, and forward/reverse playback caching to prevent sluggish frame drops or rendering artifacts during fast scrubbing.
- Cache Eviction & Memory Bounds: Ensure decoded frame memory pools and decoder caches have strict LRU (Least Recently Used) or capacity boundaries to prevent out-of-memory crashes on long high-resolution timelines.

### 7. C# 13, .NET 9 & NativeAOT / Trimming Compliance
- AOT & Trim Compatibility: Flag reflection traps (Type.GetType, MakeGenericType, un-annotated dynamic type creation), reflection-based serialization, and missing [DynamicallyAccessedMembers] annotations. Enforce compile-time source generators (e.g., System.Text.Json source generation via [JsonSerializable]).
- Unmanaged Memory, P/Invoke & Native Resource Safety: Audit [DllImport] and [LibraryImport] signatures for non-blittable types and GC pointer tracking. Flag unsafe pointer conversion anti-patterns (e.g., untracked Unsafe.AsPointer<T> without fixed pinning scopes) and ensure safe lifecycle ownership for native handles, COM objects, and `NativeMemory` allocations (enforcing strict `SafeHandle` cleanup patterns).
- Allocation Hot Paths & GC Churn: Audit per-frame allocations, boxing, string formatting, and closures inside high-frequency scrubbing or playback loops. Enforce zero-allocation primitives (Span<T>, ReadOnlySpan<T>, Memory<T>, ArrayPool<T>, ref struct).

### 8. Architectural Monoliths, Bloat & Code Duplication
- God Class Decomposition: Flag classes exceeding 1,500 lines that mix UI routing, rendering, state caching, and business math. Decouple these into cohesive, testable domain controllers.
- DRY & Algorithm Consolidation: Detect duplicated coordinate math, zoom clamping, and timeline transformation algorithms across views, consolidating them into pure domain services.

### 9. Logging Pipeline Health & Silent Error Swallowing
- Silent Exception Swallowing: Audit all bare catch { } blocks and generic catch (Exception ex) { Log(ex); } statements hiding failing Win32 calls, driver crashes, audio dropouts, or I/O locks. Enforce explicit fallback logic, structured error categorization, and actionable user error reporting.
- Asynchronous & Bounded Logging: Ensure logging operations do not perform synchronous disk I/O on hot paths. Logging must route through a non-blocking background queue with strict rolling file size thresholds (e.g., 5MB–10MB maximum) to prevent unbounded disk growth.

### 10. Layout Lifecycle & Input Routing
- Layout Thrashing: Detect size mutations or layout invalidations (InvalidateMeasure/InvalidateArrange) fired inside arrange/render passes that induce layout loops.
- Centralized Focus & Hotkey Scoping: Ensure keyboard shortcuts route through a unified input service that suspends global timeline triggers when text fields or modal dialogs hold focus.
