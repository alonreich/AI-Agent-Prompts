AUDIT CATEGORIES:
1. DESIGN SYSTEM & STYLE BREAKAGE: Hardcoded assets, design token/variable duplication, broken theme inheritance, and disconnected style bindings.
2. STATE MANAGEMENT & ARCHITECTURAL FLAWS: Broken data contexts, improper event handlers, missing state bindings on input controls, and missing loading/disabled/error visual states.
3. PERFORMANCE & RENDER TREE REFACTORING: Excessive DOM/layout nesting, abusive usage of expensive reactive computations, hardcoded dimensions breaking responsiveness/scaling, and risky absolute positioning or margin abuse.
4. MICRO-INTERACTION & ACCESSIBILITY ACCURACY: Missing pointer cursors on interactive controls, unconfigured focus/hover/active states within component templates, and obvious WCAG 2.2 focus navigation gaps visible in markup.
5. ERROR FEEDBACK & COGNITIVE FRICTION: Missing DataValidationErrors templates, absent inline text warnings for destructive operations, or lack of explicit watermarks/placeholders in data-entry fields.
6. VISUAL HIERARCHY & CONTRAST DEVIATION: Identical styling applied to primary and secondary actions in the same layout pane, missing distinct Header text properties on control groups, and layout configurations that mix multi-step wizards without explicit visual step indicators.

KNOWN STATIC AUDIT BLIND SPOTS (FLAG AS RUNTIME RISKS):
- Runtime Rendering & Clipping: Unforeseen element collisions, text overflow, and clipping during window resizing/viewport shifts.
- Subjective Aesthetics & Harmony: Overall visual appeal and color palette clashing.
- Animation Fluidity: Actual frame rates, transition smoothness, and GPU rendering bottlenecks.
- Real-World Localization: Layout breakage caused by varying string lengths or RTL languages.
- Complex Interactivity & Gestures: Drag-and-drop fluidity, multi-touch behavior, and dynamic script-based visual state triggers.
- Actual Focus Traversal: Real-world keyboard tab navigation flow across dynamically injected views.
- Dynamic Validation Clarity: Whether an error message dynamically rendered from the ViewModel is actually legible, clear, and actionable to an average user.
- Information Density Friction: Overwhelming UI complexity caused by displaying more than 7 high-context controls simultaneously without visual separation or progressive disclosure.
