AUDIT CATEGORIES:
1. DESIGN SYSTEM, ICONS & VISUAL LANGUAGE: Hardcoded assets, theme inheritance, disconnected style bindings, and consistent icon style, size, meaning, and tooltips.
2. STATE MANAGEMENT, LOADING & ACTION FEEDBACK: Broken data contexts, missing loading/empty/error visual states, and clear feedback for save success, progress, undo, destructive-action warnings, or failed data.
3. PERFORMANCE, RESPONSIVENESS & SCALING: Excessive DOM nesting, hardcoded dimensions breaking responsiveness/resizing/DPI/clipping/overflow, and risky absolute positioning.
4. ACCESSIBILITY & MICRO-INTERACTIONS: Missing pointer cursors, WCAG 2.2 focus navigation gaps, keyboard use, focus order, screen-reader labels, and tap target sizes.
5. FORMS, INPUT UX & ERROR COGNITIVE FRICTION: Labels, validation, required fields, defaults, input clarity, absent inline text warnings for destructive operations, and explicit placeholders.
6. VISUAL HIERARCHY & CONTRAST DEVIATION: Identical styling applied to primary and secondary actions, missing distinct Header text properties, and multi-step wizards without explicit visual step indicators.
7. NAVIGATION & SCREEN FLOW: Static evaluation of menus, back behavior, tabs, and logical routing movement between screens.
8. DIALOGS & WINDOW BEHAVIOR: Modal size constraints, close/cancel behavior, focus trapping, and z-index stacking.
9. TERMINOLOGY & CONTENT CONSISTENCY: Same action, name, and wording used consistently across app components.
10. LOCALIZATION & RTL (STATIC FLAGS): Hardcoded LTR constraints (e.g., margin-left vs margin-inline) affecting Hebrew support, long text alignment, and mixed Hebrew/English handling.

KNOWN STATIC AUDIT BLIND SPOTS (FLAG AS RUNTIME RISKS):
- Runtime Rendering & Clipping: Unforeseen element collisions, text overflow, and clipping during window resizing/viewport shifts.
- Subjective Aesthetics & Harmony: Overall visual appeal and color palette clashing.
- Animation Fluidity: Actual frame rates, transition smoothness, and GPU rendering bottlenecks.
- Real-World Localization: Layout breakage caused by varying string lengths or RTL languages.
- Complex Interactivity & Gestures: Drag-and-drop fluidity, multi-touch behavior, and dynamic script-based visual state triggers.
- Actual Focus Traversal: Real-world keyboard tab navigation flow across dynamically injected views.
- Dynamic Validation Clarity: Whether an error message dynamically rendered from the ViewModel is actually legible, clear, and actionable to an average user.
- Information Density Friction: Overwhelming UI complexity caused by displaying more than 7 high-context controls simultaneously without visual separation or progressive disclosure.
