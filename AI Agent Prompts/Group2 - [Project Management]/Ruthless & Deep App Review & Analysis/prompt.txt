## SYSTEM AUDIT DOMAINS & INVESTIGATION VECTORS
Systematically audit the repository against these architectural domains:

### 1. Concurrency, Race Conditions & State Tearing
- Insidious & High-Risk Race Conditions:
  - Detect Time-of-Check to Time-of-Use (TOCTOU) races where file existence, service readiness, or collection bounds are checked without continuous synchronization.
  - Detect out-of-order asynchronous completion: during rapid user input, background data fetching, or filtering, verify whether an earlier slow asynchronous task can resolve after a newer one and overwrite current state.
  - Audit multi-threaded or multi-async collection access (e.g., standard mutable collections modified concurrently without proper locks or thread-safe primitives/immutable snapshots).
- Lock Contention on the Primary Thread: Audit every synchronous lock, mutex, or semaphore acquisition on the main execution thread. Flag locks shared between the main thread and background worker threads that can induce micro-stutters, UI freezes, or deadlocks.
- Async Hygiene & Sync-over-Async: Flag all blocking invocations on asynchronous operations (.Result, .Wait(), blocking block-waits) on the main thread or critical paths.
- Background Worker & Queue Pipelines: Ensure heavy workloads (data parsing, bulk processing, cryptographic hashing, heavy computation) run off the main thread via decoupled background workers using non-blocking message pipelines or channels.
- Timer & Polling Saturation: Replace uncoordinated polling timers driving application state with push-based reactive streams, event-driven hooks, or hardware/runtime-synced execution loops.

### 2. Defensive Storage, Path Handling & Crash Persistence
- File System & Storage Fragility:
  - Verify that file-saving or data-persistence routines never assume target paths, buckets, or directories exist. Audit for missing creation or existence checks before export or state writes.
  - Flag path/key sanitization flaws: verify handling of invalid characters, illegal symbols across storage systems, path length limits, and directory traversal/escape vulnerabilities.
  - Audit error handling for external storage disconnections, read-only media, permission denials, and out-of-space/quota exhaustion conditions.
- Atomic Persistence & Anti-Corruption:
  - Flag direct-to-destination writes for critical user data or session recovery files. Enforce atomic write patterns (write to unique temporary location -> flush/sync to physical storage -> atomic file/key replacement).
  - Ensure state serialization never blocks user interaction. State must be snapshotted in memory and written asynchronously via background workers, diffing state deltas rather than serializing full trees on hot paths.
- In-Memory IPC vs. External Serialization: Flag sub-system transitions or internal communication channels that serialize state to disk files or temporary storage to pass data between components or processes. Migrate inter-process/inter-component communications to high-throughput shared memory, managed streams, or secure message channels.

### 3. Pipeline Performance, Resource Management & High-Throughput Buffering
- Zero-Copy & Memory Invariants: Trace data flow from input sources to output presentation or storage. Flag redundant memory copying, serialization round-trips, or unnecessary allocations across execution boundaries.
- Dynamic Workload Allocation: Ensure optimal balancing across system resources (e.g., offloading CPU-heavy crunching to background pools while maintaining responsive execution loops). Ensure resources are neither starved nor over-saturated by misplaced tasks.
- Global Clock & Synchronization Drift: Ensure multi-stream or multi-source data streams derive synchronization from a single authoritative timeline or clock source, preventing drift, phase jitter, or out-of-sync outputs.

### 4. Data Validation, State Integrity & Serialization Safety
- Schema & Boundary Integrity: Audit data ingestion pipelines for accurate parsing and validation of strict schemas, format versions, and metadata limits to prevent processing corrupted or malformed payloads.
- Range & Precision Compliance: Verify handling of numerical precision boundaries, overflow/underflow protections, and normalization paths to avoid clipping, rounding errors, or logical corruption.
- Memory Layout & Structural Formats: Audit cross-component handoffs for complex data structures, ensuring correct alignment, padding, and indexing match target resource expectations without buffer overflows or data corruption.

### 5. Real-Time Constraints, Event Loops & Non-Blocking Execution
- Critical Loop Safety: Audit tight loops or real-time execution threads (such as audio/video callbacks, high-frequency event handlers, or render loops) for illegal operations. Flag any memory allocations, garbage collection triggers, lock acquisitions, or blocking system calls that cause immediate dropouts, frame skips, or stutter.
- Buffer Management & Synchronization: Ensure lock-free ring buffers, object pools, or atomic transfer queues manage data safely between producer and consumer threads without thread starvation.

### 6. Caching Strategies, Memory Bounds & Eviction Topologies
- Precision & Responsiveness: Audit caching logic for handling complex access patterns, partial loads, and forward/reverse state caching to prevent sluggish performance or memory bloat during intensive operations.
- Cache Eviction & Memory Bounds: Ensure cached data structures and memory pools have strict LRU (Least Recently Used), TTL, or capacity boundaries to prevent out-of-memory crashes under heavy load or long-running sessions.

### 7. Ecosystem Best Practices, Runtime Performance & Compilation Safety
- Reflection & Dynamic Traps: Flag fragile reflection usage, dynamic code generation, or un-annotated metadata dependencies that break strict compilation, ahead-of-time (AOT) compilation, tree-shaking, or minification passes. Enforce compile-time code generation or explicit type safety annotations where applicable.
- Unmanaged Memory & Resource Safety: Audit low-level pointer arithmetic, foreign function interfaces (FFI), or unmanaged memory bindings for non-blittable types and tracking safety. Flag unsafe pointer conversions without proper scoping, and ensure strict lifecycle ownership for native handles, file descriptors, and dynamic memory allocations (enforcing strict resource-release or RAII patterns).
- Allocation Hot Paths & Garbage Collection Churn: Audit per-frame or per-iteration allocations, boxing, string formatting, and closures inside high-frequency loops. Enforce zero-allocation primitives, object pooling, or stack-allocated buffers where performance is critical.

### 8. Architectural Monoliths, Bloat & Code Duplication
- God Class Decomposition: Flag files or modules exceeding strict line-count thresholds that mix UI routing, state caching, business logic, and data access. Decouple these into cohesive, testable domain controllers and single-responsibility services.
- DRY & Algorithm Consolidation: Detect duplicated coordinate math, validation routines, and transformation algorithms across components, consolidating them into pure, reusable domain services.

### 9. Logging Pipeline Health & Silent Error Swallowing
- Silent Exception Swallowing: Audit all bare catch blocks and generic catch statements hiding failing system calls, driver crashes, network drops, or resource locks. Enforce explicit fallback logic, structured error categorization, and actionable user error reporting.
- Asynchronous & Bounded Logging: Ensure logging operations do not perform synchronous disk or network I/O on hot paths. Logging must route through a non-blocking background queue with strict rolling file size or retention thresholds to prevent unbounded disk growth.

### 10. UI/Client Lifecycle, State Management & Event Routing
- Layout & Render Thrashing: Detect size mutations, style recalculations, or layout invalidations fired inside render/layout passes that induce infinite loops or performance degradation.
- Centralized Focus & Event Scoping: Ensure user input events and shortcuts route through a unified input service that correctly scopes context (e.g., suspending global triggers when text fields, modals, or specialized sub-components hold focus).
